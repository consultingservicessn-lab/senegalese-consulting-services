Preparing a request

What helps us assess your translation request?

A clear brief helps define the source material, languages and expected deadline. Each document is different, so the following details make the request easier to assess.

Specify the languages

Identify the original language and the language required. For multilingual material, list each version you need.

Describe the document

Tell us whether it is business, administrative, technical or legal material, along with the file format and approximate number of pages or words.

Explain the purpose and deadline

The intended audience, use of the document, target date and any glossary or style guide may help clarify the scope.

Official documents

If your process requires a certified translation or a specific formal requirement, mention it at the start so applicable conditions can be clarified.
